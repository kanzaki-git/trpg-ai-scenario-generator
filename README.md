# 1. サービス概要

TRPGを遊びたいと思った時に、わずか数分でゲームマスターが利用できるシナリオを生成できるAIシナリオ生成サービスです。

TRPG初心者でも、ジャンルや世界観などを選択するだけで、シナリオの導入、NPC、イベント、エンディングまで含んだセッション用シナリオを作成できます。

シナリオ探しや購入、ゲームマスターによる事前準備の負担を減らし、「遊びたい」と思った時にすぐ遊べる環境を提供します。

---

# 2. このアイデアはどこから生まれたか

## 2-1. きっかけとなった体験・感情

私はTRPGの配信やリプレイ動画を見ることが好きで、自分でも遊んでみたいと思っていました。

実際に友人とTRPGを遊ぼうとした際、まずBOOTHでシナリオを探す必要がありました。しかし、自分たちに合ったシナリオを探すだけでも時間がかかり、さらにゲームマスターは事前にシナリオを読み込んで内容を把握する必要がありました。

その結果、「今日はTRPGを遊ぶつもりだったのに、準備だけで終わってしまった」という経験をしました。

ゲームであれば思い立った時にすぐ遊べるものが多い一方で、TRPGは遊ぶ前の準備が多く、そのハードルの高さに不便さを感じました。

そこで、「もっと気軽にTRPGを始められる仕組みがあれば、初心者でも遊びやすくなるのではないか」と考え、このサービスを思いつきました。

## 2-2. なぜそれが気になったのか

私はゲームを遊ぶ際に、できるだけ手軽に始められることを重視しています。

また、面白そうなコンテンツでも、始めるまでの準備や手間が多いと途中で諦めてしまう人は少なくないと感じています。

TRPGは非常に魅力的な遊びですが、シナリオ探しや購入、ゲームマスターによる準備など、遊ぶ前に必要な作業が多くあります。

そのため、本来ならもっと多くの人が楽しめるはずなのに、準備の負担が原因で遊ぶ機会を逃している人がいるのではないかと感じました。

私は、TRPGを遊びたいと思った時にすぐ遊び始められる環境を作り、より多くの人が気軽にTRPGへ触れられるようにしたいと考えています。

## 4-2. 自分とユーザーの距離

過去の自分

私自身がTRPG配信を見て興味を持ち、実際に遊ぼうとした際にシナリオ探しや準備の負担を感じた経験があるためです。

## 4-3. 実際に使われる可能性について

最初に利用してくれるのは、TRPG配信やリプレイ動画を見て興味を持ったものの、ゲームマスター経験がなく最初のセッションを開催できていない人だと考えています。

友人との会話で「TRPGをやってみたい」という話になった時や、実際にセッションを企画することになった時に利用されることを想定しています。

現在はChatGPTやClaude、BOOTH、TALTOなどが代替手段として利用されています。

しかし本サービスは、シナリオ生成そのものではなく、ゲームマスター未経験者が最初のセッションを開催するための支援に価値があります。

TRPGに必要な情報を整理した状態で出力することで、シナリオ選びや準備への不安を減らし、最初の一歩を踏み出しやすくします。

## 4-4. ユーザーがサービスを導入して利用するまでのイメージ

ユーザーは「友人とTRPGをやってみたいが、どのシナリオを選べばよいかわからない」「ゲームマスターをやる自信がない」と感じた時にサービスへアクセスします。

ジャンルや世界観、プレイ人数などを入力すると、AIがゲームマスター向けのシナリオを生成します。

生成されたシナリオは保存・編集でき、そのままセッション準備に利用できます。

初回はゲームマスター未経験者が最初のセッションを開催するために利用し、その後は過去に作成したシナリオを管理・再利用しながら継続利用することを想定しています。

# 6. このサービスで提供したい価値

## 6-1. ユーザーの変化

### 行動の変化

これまで「ゲームマスターは経験者がやるもの」と考え、TRPGを遊ぶ側に回っていた人が、「AIがシナリオ作成をサポートしてくれるなら自分にもできそう」と感じ、ゲームマスターへ挑戦できるようになる。

また、シナリオ探しや準備に時間をかけることなく、友人と「今度TRPGをやろう」となった時にすぐセッションを開催できるようになる。

### 気持ちの変化

「シナリオ準備に何時間もかかるのではないか」「ゲームマスターは難しそう」という不安から、「数分でシナリオが作れるならやってみよう」という前向きな気持ちへ変わる。

### 考え方の変化

「TRPGは事前準備が必須で計画的に遊ぶもの」という認識から、「思い立った時に気軽に遊べるもの」という認識へ変わる。

## 6-2. 価値を一文で表す

このサービスは、TRPGを遊びたいけれどシナリオ準備の負担で行動できない人が、短時間でシナリオを用意し、その日のうちにセッションを始められるようになるサービスです。

## 8. このアプリの懸念点とその対策

## 懸念点①

### 何が問題になりそうか

ChatGPTなど既存の生成AIサービスとの差別化が難しい可能性がある。

### なぜそう思うか

既存の生成AIでもTRPGシナリオを作成できるため、単純なシナリオ生成機能だけでは利用する理由が弱くなる可能性がある。

### そのために考えている対策

* ゲームマスター未経験者向けに、シナリオ作成だけでなくセッション開催までを支援するサービスとして設計する
* 世界観、導入、NPC、イベント、エンディング候補など、ゲームマスターが利用しやすい形で情報を整理して出力する
* シナリオ選びや準備に不安を感じる初心者が、最初のセッションを開催できる体験を提供する

## 懸念点②

### 何が問題になりそうか

生成されるシナリオ品質が安定しない可能性がある。

### なぜそう思うか

AI生成結果は入力内容やプロンプト設計によって品質が変化するため、実際のセッションで利用しづらい内容が生成される可能性がある。

### そのために考えている対策

* OpenAI APIへ渡すプロンプトを継続的に改善する
* 実際に生成したシナリオを用いてテストを行い、出力内容を検証する
* シナリオ編集機能を実装し、ユーザー自身で調整できるようにする
* 本リリースではテンプレート機能を追加し、品質の安定化を図る

## 懸念点③

### 何が問題になりそうか

ユーザーが継続利用しない可能性がある。

### なぜそう思うか

シナリオ生成だけでは一度利用して満足してしまい、他の生成AIサービスへ移行する可能性があるため。

### そのために考えている対策

* 生成したシナリオを保存・編集できるようにし、自分専用のシナリオ集として活用できるようにする
* 本リリースではシナリオ共有機能を実装し、他ユーザーのシナリオを参考にできるようにする
* セッション進行支援機能を追加し、シナリオ生成だけでなくゲームマスター活動全体を支援するサービスへ発展させる

# 9. 今後の展開・発展の方向性

## 機能追加の方向性

* セッション進行支援機能

## UI・体験の改善

* より少ない入力でシナリオを生成できるUI
* シナリオテンプレート機能
* スマートフォン対応強化

## 機能以外の工夫

* 人気シナリオランキング
* コミュニティ形成
* シナリオ共有文化の促進

### 一度目に選ばれる理由

TRPGに興味はあるものの、シナリオ選びやゲームマスター準備に不安を感じている初心者でも、必要な情報を入力するだけでセッション用シナリオを作成できるため。

### ユーザーはなぜ使い続けるか

生成したシナリオを保存・編集しながら管理できるため、セッションを重ねるごとに自分専用のシナリオ集として活用できる。

また、本リリースでシナリオ共有機能を実装することで、他ユーザーのシナリオを参考にしたり、自分のシナリオを共有したりできる環境を作りたいと考えている。

さらに、セッション進行支援機能を追加することで、シナリオ生成だけでなくゲームマスター活動全体をサポートするサービスへ発展させることを目指している。

### データが溜まると何ができるか

* 人気ジャンルや人気世界観の分析
* ユーザーごとのおすすめシナリオ提案
* 人気設定を元にしたシナリオテンプレート生成
* ユーザー同士の交流促進
* 初心者ゲームマスター向けのおすすめ設定や導入例の提案
