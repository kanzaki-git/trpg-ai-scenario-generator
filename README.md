# 1. サービス概要

TRPGを遊びたいと思った時に、わずか数分でゲームマスターが利用できるシナリオを生成できるAIシナリオ生成サービスです。

TRPG初心者でも、ジャンルや世界観などを選択するだけで、シナリオの導入、NPC、イベント、エンディングまで含んだセッション用シナリオを作成できます。

シナリオ探しや購入、ゲームマスターによる事前準備の負担を減らし、「遊びたい」と思った時にすぐ遊べる環境を提供します。

---

# 2. このアイデアはどこから生まれたか

## 2-1. きっかけとなった体験・感情

私はTRPGの配信やリプレイ動画を見ることが好きで、自分でも遊んでみたいと思っていました。

実際に友人とTRPGを遊ぼうとした際、まずBOOTHでシナリオを探す必要がありました。しかし、自分たちに合ったシナリオを探すだけでも時間がかかり、さらにゲームマスターは事前にシナリオを読み込んで内容を把握する必要がありました。

その結果、「今日はTRPGを遊ぶつもりだったのに、準備だけで終わってしまった」という経験をしました。

ゲームであれば思い立った時にすぐ遊べるものが多い一方で、TRPGは遊ぶ前の準備が多く、そのハードルの高さに不便さを感じました。

そこで、「もっと気軽にTRPGを始められる仕組みがあれば、初心者でも遊びやすくなるのではないか」と考え、このサービスを思いつきました。

## 2-2. なぜそれが気になったのか

私はゲームを遊ぶ際に、できるだけ手軽に始められることを重視しています。

また、面白そうなコンテンツでも、始めるまでの準備や手間が多いと途中で諦めてしまう人は少なくないと感じています。

TRPGは非常に魅力的な遊びですが、シナリオ探しや購入、ゲームマスターによる準備など、遊ぶ前に必要な作業が多くあります。

そのため、本来ならもっと多くの人が楽しめるはずなのに、準備の負担が原因で遊ぶ機会を逃している人がいるのではないかと感じました。

私は、TRPGを遊びたいと思った時にすぐ遊び始められる環境を作り、より多くの人が気軽にTRPGへ触れられるようにしたいと考えています。

## 4-2. 自分とユーザーの距離

過去の自分

私自身がTRPGに興味を持ち、実際に遊ぼうとした際に準備の大変さを感じた経験があるためです。

## 4-3. 実際に使われる可能性について

最初に利用してくれるのは、TRPG配信を見て興味を持った初心者や、初めてゲームマスターに挑戦する人だと考えています。

友人との会話で「今度TRPGをやってみよう」となった時や、セッション開催が決まった時に利用することを想定しています。

現在はChatGPTやClaude、BOOTH、TALTOなどが代替手段として利用されています。

しかし本サービスは、TRPG向けに特化した入力フォームを利用することで、プロンプト作成やシナリオ探しの手間なく、短時間でセッションを始められる点に価値があります。

## 4-4. ユーザーがサービスを導入して利用するまでのイメージ

ユーザーは「TRPGをやりたいけどシナリオがない」と感じた時にサービスへアクセスします。

ジャンルや世界観、プレイ人数などを入力すると、AIがTRPG向けシナリオを生成します。

生成されたシナリオは保存・編集でき、そのままセッションに利用できます。

セッションごとに新しいシナリオが必要になるため、継続利用が期待できます。

# 5. 既存サービス・競合調査

| サービス    | できること      | 課題                | 本サービスとの違い        |
| ------- | ---------- | ----------------- | ---------------- |
| ChatGPT | TRPGシナリオ生成 | プロンプトを考える必要がある    | フォーム入力だけで生成できる   |
| Claude  | 長文シナリオ生成   | TRPG向けに最適化されていない  | TRPG向け構造で出力される   |
| BOOTH   | シナリオ購入     | 探す手間や購入費用が発生する    | 条件に合わせて即時生成できる   |
| TALTO   | シナリオ検索・閲覧  | 自分に合うシナリオを探す必要がある | 希望条件からシナリオを生成できる |

## 5-2. それでも自分が作りたい理由

既存サービスでもシナリオ生成やシナリオ購入は可能です。

しかし、TRPG初心者にとっては「どのようなプロンプトを書けばよいかわからない」「自分たちに合ったシナリオを探すのが大変」といった問題があります。

私が実現したいのはシナリオ生成そのものではなく、「TRPGをやりたいと思った時にすぐ遊べる状態を作ること」です。

そのため、TRPGに必要な項目を選択するだけでシナリオを生成し、準備の負担を最小限にするサービスを作りたいと考えています。

## 5-3. 差別化を体験価値で表現する

「TRPG配信を見て興味を持った初心者が、ゲームマスター経験やシナリオ知識がなくても、その日のうちにセッションを開催できる体験」

# 6. このサービスで提供したい価値

## 6-1. ユーザーの変化

### 行動の変化

これまで「ゲームマスターは経験者がやるもの」と考え、TRPGを遊ぶ側に回っていた人が、「AIがシナリオ作成をサポートしてくれるなら自分にもできそう」と感じ、ゲームマスターへ挑戦できるようになる。

また、シナリオ探しや準備に時間をかけることなく、友人と「今度TRPGをやろう」となった時にすぐセッションを開催できるようになる。

### 気持ちの変化

「シナリオ準備に何時間もかかるのではないか」「ゲームマスターは難しそう」という不安から、「数分でシナリオが作れるならやってみよう」という前向きな気持ちへ変わる。

### 考え方の変化

「TRPGは事前準備が必須で計画的に遊ぶもの」という認識から、「思い立った時に気軽に遊べるもの」という認識へ変わる。

## 6-2. 価値を一文で表す

このサービスは、TRPGを遊びたいけれどシナリオ準備の負担で行動できない人が、短時間でシナリオを用意し、その日のうちにセッションを始められるようになるサービスです。

# 8. このアプリの懸念点とその対策

## 懸念点①

### 何が問題になりそうか

ChatGPTなど既存サービスとの差別化が難しい可能性がある。

### なぜそう思うか

既存の生成AIでもTRPGシナリオを作成できるため。

### そのために考えている対策

* ジャンル、世界観、プレイ人数などを選択するだけで利用できるTRPG専用フォームを提供する
* 世界観、NPC、イベント、エンディング候補などゲームマスターがそのまま利用できる形式で出力する
* シナリオ保存・編集機能を実装し、継続利用しやすくする

## 懸念点②

### 何が問題になりそうか

生成されるシナリオ品質が安定しない可能性がある。

### なぜそう思うか

AI生成結果は入力内容やプロンプト設計によって品質が変化するため。

### そのために考えている対策

* OpenAI APIへ渡すプロンプトを継続的に改善する
* 生成後の編集機能を実装する
* 本リリースではテンプレート機能を追加し、品質の安定化を図る

## 懸念点③

### 何が問題になりそうか

ユーザーが継続利用しない可能性がある。

### なぜそう思うか

一度シナリオを生成しただけで満足してしまう可能性があるため。

### そのために考えている対策

* シナリオ保存機能により過去のシナリオを再利用できるようにする
* 本リリースでシナリオ共有機能を実装する
* セッション進行支援機能を追加し、シナリオ生成以外の価値も提供する

### ユーザーはなぜ使い続けるか

TRPGではセッションごとに新しいシナリオが必要になるため継続的な需要がある。

また、保存したシナリオを見返しながら新しいシナリオ作成に活用できるため、繰り返し利用する動機が生まれる。

さらに、本リリースでシナリオ共有機能を実装することで、他ユーザーの作品から刺激を受け、新しいシナリオ作成につながることを期待している。

### データが溜まると何ができるか

* 人気ジャンルや人気世界観の分析
* ユーザーごとのおすすめシナリオ提案
* 人気設定を元にしたテンプレート生成
* ユーザー同士の交流促進
